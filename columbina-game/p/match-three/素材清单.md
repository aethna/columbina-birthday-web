# 消消乐素材库

当前素材为六种角色头像方块，每种提供普通状态和四种特殊状态。特殊状态已为每种方块加入对应色系的背景光晕；原始特殊图另存于 `tiles/special-originals/`。棋盘底图取自五子棋原图中央连续 10×10 格，外围装饰已裁掉。

## 方块素材

### 普通方块：`tiles/normal/`

- `gem-01.png` 至 `gem-06.png`：六种普通方块，编号与原图保持一致。

### 特殊方块：`tiles/special/`

每种特殊形态各有六张角色对应图，文件名中的编号与普通方块一致。背景光晕颜色按方块编号统一：

| 编号 | 光晕颜色 |
| --- | --- |
| 01 | 薰衣草紫 |
| 02 | 叶片绿 |
| 03 | 冰川蓝 |
| 04 | 紫罗兰 |
| 05 | 玫瑰粉 |
| 06 | 青空蓝 |

- `line-horizontal/gem-01.png` 至 `gem-06.png`：横向线特殊方块
- `line-vertical/gem-01.png` 至 `gem-06.png`：纵向线特殊方块
- `area-bomb/gem-01.png` 至 `gem-06.png`：范围炸弹
- `color-bomb/gem-01.png` 至 `gem-06.png`：彩色炸弹
- `special-originals/<类型>/gem-01.png` 至 `gem-06.png`：加光晕前的原始特殊图备份

### 光晕处理说明

- 横线、竖线和范围炸弹保留原有形状，背景特效改为对应方块的颜色，并增加柔和外发光。
- 彩色炸弹使用对应颜色的渐变底和角色周围的柔光。
- 角色图主体保持原样；普通方块图未修改。

## 棋盘

- `board/board-10x10.png`：从 `columbina-game/p/event/gomoku-board.png` 中心棋格区域裁切，保留 10×10 个完整方格、网格线和蓝色底纹；外围花纹已裁掉。

## 其他待补素材目录

- `effects/`：消除、特殊触发、连锁等视觉特效
- `ui/`：分数、步数、排行榜等界面图标
- `audio/`：交换、消除、连锁和结算音效
